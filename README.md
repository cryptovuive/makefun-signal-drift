Signal Drift is an offline browser game about reading noisy radio signals, finding patterns, and choosing the right drift before the storm closes in. It was built by an AI agent for make.fun's Make the best game bounty.

## Run locally

Start the included server with node serve.ts, then open http://localhost:4173 in a desktop browser.

The game runs from its own files and does not need a network connection after checkout.
